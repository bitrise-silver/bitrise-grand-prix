# Marketing art

Drop PNG or JPG images here and point a billboard at one from a track file:

```json
{ "at": 2.5, "offset": 13, "image": "res://assets/marketing/my-banner.png" }
```

A billboard with an `image` shows only that image (about 2:1 works best); without one it
shows an icon and a slogan. Brand artwork is not covered by the code licence, see `NOTICE.md`.
